# فارسی‌فای

افزونهٔ Chrome برای فونت فارسی، راست‌چین کردن صفحه و نمایش Markdown.

متنِ کادر افزونه مستقیم در حالت خواندن باز می‌شود: `**متن**` بولد، `## عنوان` تیتر و فهرست‌ها با شماره‌گذاری و زیر‌فهرست نمایش داده می‌شوند. با «ویرایش متن» می‌توان به متن اصلی برگشت. متن، فایل، پوشه و آدرس انتخاب‌شده در تب کنار همان تبی باز می‌شوند که افزونه را از آن باز کرده‌ای.

## ابزارهای خواندن و ذخیره

- متن هر سند خودکار و جداگانه در مرورگر ذخیره می‌شود. رفرش، باز کردن دوبارهٔ آدرس سند یا بازیابی تب بسته‌شده با `Ctrl+Shift+T` متن را برمی‌گرداند. فونت، اندازه و حالت خواندن یا ویرایش هم حفظ می‌شوند.
- فهرست تیترها کنار سند نمایش داده می‌شود؛ روی هر تیتر کلیک کن تا به همان بخش بروی. دکمهٔ «فهرست تیترها» آن را مخفی یا نمایش می‌دهد.
- هر بلوک کد دکمهٔ «کپی کد» دارد که فقط متن اصلی کد را کپی می‌کند.
- چک‌لیست‌های `- [ ]` و `- [x]` قابل تغییرند. تیک زدن، علامت همان مورد را در متن Markdown تغییر می‌دهد و در نسخهٔ ذخیره‌شدهٔ افزونه نگه می‌دارد. فایل اصلی روی دیسک تغییر نمی‌کند.
- «خروجی HTML» یک فایل مستقل برای ارسال یا مطالعهٔ آفلاین می‌سازد. فونت انتخاب‌شده، تصاویر در دسترس، فهرست تیترها و وضعیت چک‌لیست داخل فایل قرار می‌گیرند. چک‌لیست در خروجی فقط وضعیت ذخیره‌شده را نمایش می‌دهد. لینک‌های فایل داخل پوشهٔ انتخاب‌شده که مسیر کامل قابل حمل ندارند، به صورت متن با توضیح مسیر باقی می‌مانند.

متن‌های ذخیره‌شده داخل همین مرورگر نگه داشته می‌شوند؛ پاک کردن داده‌های افزونه یا حذف آن، این نسخه‌ها را پاک می‌کند. برای داشتن یک نسخهٔ مستقل از خروجی HTML استفاده کن.

## تصاویر و لینک‌های سند

پس از تغییر کد، افزونه را در `chrome://extensions` با دکمهٔ Reload دوباره بارگذاری کن.

برای باز کردن داک محلی، مسیر کاملش را در کادر بارگذاری وارد کن، مثلاً:

```text
E:\factorland_localhost\docs\qa-local-shop-name-device-2026-10-05.md
```

برای خواندن مسیر مستقیم فایل، در صفحهٔ Details افزونه گزینهٔ **Allow access to file URLs** را فعال کن. این تنظیم توسط خود مرورگر کنترل می‌شود.

روش دیگر، انتخاب پوشهٔ پروژه با «انتخاب پوشه» است. تصاویر و فایل‌های مرتبط باید داخل همان پوشه یا زیرپوشه‌های آن باشند. برای لینک‌هایی مثل `../app/Shop.php` ریشهٔ پروژه را انتخاب کن، نه فقط پوشهٔ `docs`.

اگر فقط یک فایل را با «انتخاب فایل» باز کنی، کنار تصاویر دکمهٔ «انتخاب پوشهٔ منبع تصاویر» نمایش داده می‌شود. آن را بزن و پوشهٔ داک یا ریشهٔ پروژه را انتخاب کن؛ همان داک دوباره تصاویرش را نمایش می‌دهد. انتخاب یک فایل به افزونه دسترسی به فایل‌های کناری نمی‌دهد. متنِ کپی‌شده هم برای لینک نسبی به منبع نیاز دارد؛ داک را از مسیر کامل یا پوشه باز کن.

تصاویر استاندارد Markdown و لینک‌های معمولی به تصویر، هر دو داخل سند نمایش داده می‌شوند:

```md
![تصویر](qa-assets/screen.png)
[تصویر](qa-assets/screen.png)
[تصویر با فاصله در نام](<qa-assets/my screen.png>)
```

با کلیک روی تصویر، تصویر در تب جدید نمایش‌دهنده باز می‌شود. تصویر ناموجود یا دسترسی نامعتبر، پیام مشخصی نشان می‌دهد.

لینک فایل‌ها هم در تب جدید باز می‌شود. مسیر نسبی از محل داک فعلی محاسبه می‌شود و در آدرس تب مقصد حفظ می‌شود:

```md
[داک دیگر](other.md)
[بخش مشخص](other.md#عنوان-بخش)
[خط ۲۷۳](../app/Shop.php#L273)
[خط‌های ۲۷۳ تا ۲۸۰](../app/Shop.php#L273-L280)
[خط ۲۷۳](../app/Shop.php:273)
```

فایل کد یا سند دارای شمارهٔ خط، به صورت متن منبع با شمارهٔ خطوط نمایش داده می‌شود؛ صفحه به خط مقصد می‌رود و آن خط یا بازه مشخص می‌شود. شمارهٔ خط از متن واقعی فایل محاسبه می‌شود. مسیرهایی که صرفاً داخل بک‌تیک نوشته شده‌اند، متن کد هستند؛ برای کلیک‌پذیری از قالب لینک بالا استفاده کن.

فایل‌ها با دسترسی پوشهٔ File System Access API هنگام باز کردن و رفرش از دیسک خوانده می‌شوند. در مرورگر فاقد این API، انتخاب پوشه با ورودی معمولی فایل، نسخهٔ انتخاب‌شدهٔ فایل‌ها را در IndexedDB نگه می‌دارد؛ برای دیدن تغییرات جدید دیسک باید پوشه را دوباره انتخاب کنی.

## بررسی تغییرات

تست مسیرها بدون وابستگی اضافی:

```powershell
node --test tests/source-paths.test.cjs
node --test tests/adjacent-tabs.test.cjs
node --test tests/task-lists.test.cjs
```

تست نمایش در Chrome بدون رابط گرافیکی:

```powershell
node tests/browser.test.cjs
node tests/browser.test.cjs 'E:\factorland_localhost\docs\qa-local-shop-name-device-2026-10-05.md'
node tests/browser.test.cjs --extension 'E:\factorland_localhost\docs\qa-local-shop-name-device-2026-10-05.md'
```

برای مسیر متفاوت Chrome، متغیر `CHROME_PATH` را تنظیم کن. تست مرورگر از پروفایل موقت استفاده می‌کند. حالت پیش‌فرض API افزونه را شبیه‌سازی می‌کند؛ با `--extension` خود افزونه با API واقعی Chrome بارگذاری می‌شود و فایل‌ها با تنظیم واقعی دسترسی فایل بررسی می‌شوند. در هر دو حالت تصاویر، DOM و IndexedDB واقعی هستند؛ دیالوگ انتخاب پوشه شبیه‌سازی می‌شود.

تست مرورگر نمایش متن فارسی، بولد، پاسخ‌های چندخطی و فهرست‌های تو‌در‌تو را هم بررسی می‌کند. در حالت `--extension`، باز شدن نتیجهٔ کادر متن کنار تب مبدأ نیز با API واقعی Chrome آزمایش می‌شود.

تست‌ها فهرست تیترها، کپی کد، تغییر و ذخیرهٔ چک‌لیست، رفرش فوری، بازیابی تب بسته‌شده و استقلال متن دو تب را بررسی می‌کنند. خروجی HTML در یک محیط مرورگر جدا، با مسدود بودن آدرس‌های شبکه و افزونه، برای نمایش فونت و تصویر آزمایش می‌شود.
